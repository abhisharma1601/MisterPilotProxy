Up and running in 3 steps

No config files. No complex setup. Just install and go.

1

Install the extension

Search for MisterPilot in the VS Code Marketplace and hit Install.

2

Add your DeepSeek key

Open the command palette, run MisterPilot: Set API Key, and paste your key from platform.deepseek.com.

3

Start coding

Click the MisterPilot icon in the sidebar and start chatting. That's it.

🔒

Your data stays yours

MisterPilot filters and anonymises all content before it reaches the AI model. Emails, credentials, phone numbers, and other PII are stripped at the source. DeepSeek never receives your raw data — only sanitised, task-relevant content is transmitted.
